# PA3 - 4a3 parcial 3

Este repositorio contiene los sistemas funcionales de coches y estudiantes desarrollados con Tkinter, POO y acceso a base de datos para la práctica del parcial 3.

## Sistemas

- `coches_system`: copia independiente del sistema de coches.
- `estudiantes_system`: copia independiente del sistema de estudiantes.

Cada sistema conserva su propio `main.py`, paquete y archivo de conexion.

## Tkinter basico

Desde esta carpeta, ejecuta cada ejemplo con Python:

```powershell
python tkinter_basico/01_ventana/ventana.py
python tkinter_basico/02_frame/frame.py
python tkinter_basico/03_texto/texto.py
python tkinter_basico/04_boton_salir/salir.py
```

En Windows tambien puedes usar `py` en lugar de `python`.

Tkinter suele venir incluido con Python.
